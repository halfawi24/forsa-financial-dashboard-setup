# Security Policy & Emergency Response

## Reporting a Security Incident

If you suspect unauthorized access:

1. Contain immediately (see runbook below).
2. Preserve evidence (do not delete logs, branches, workflow history, or audit history before capture).
3. Start secret/token/key rotation.
4. Record all actions and timestamps.

## Emergency Lockdown Runbooks

- Account/organization/repository lockdown: `docs/security/access-lockdown-runbook.md`
- Secret and credential rotation checklist: `docs/security/secret-rotation-checklist.md`
- Branch protection hardening guidance: `docs/security/branch-protection-guidance.md`

## Scope

This repository guidance supports emergency containment but does not replace GitHub account-level owner actions in Settings.
